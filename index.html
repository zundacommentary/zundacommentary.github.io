ずんだもんコメンタリー

YouTube ショートで、身近な「なぜ？」を約25秒で解説するチャンネルです。

ずんだもん（音声: VOICEVOX）が、科学・歴史・暮らしの身近な疑問を、写真と図解を使って短く解説します。内容は、公的機関・大学・百科事典などの信頼できる出典で事実を確認してから制作しています。

YouTube API Services の利用について

このチャンネルは、運営者が自分のチャンネルの運営だけに使う非公開の制作ツール「ずんだもん解説ショート投稿」で動画を作り、YouTube API Services（YouTube Data API / YouTube Analytics API）を通じて YouTube にアップロードしています。また、次の企画の改善のため、自分のチャンネルの再生回数などの統計を同 API で取得しています。このツールは一般には公開しておらず、運営者以外のアカウントには一切アクセスしません。

取得するデータとその扱いはプライバシーポリシーをご覧ください。ツールの利用には YouTube 利用規約が適用されます。

English

"Zundamon Commentary" is a YouTube Shorts channel that explains everyday questions in about 25 seconds. Videos are produced with a private, internal tool ("ずんだもん解説ショート投稿" / Zundamon Shorts Publisher) operated solely by the channel owner. The tool uses the YouTube API Services (YouTube Data API and YouTube Analytics API) only to upload videos to the owner's own channel and to read that channel's own performance statistics. It is not offered to the public and never accesses any other user's account. See our Privacy Policy and Terms of Service. By using this service you agree to be bound by the YouTube Terms of Service.
