プライバシーポリシー

Privacy Policy ／ 最終更新日: 2026年10月11日

「ずんだもん解説ショート投稿」（以下「本ツール」）は、YouTube チャンネル「ずんだもんコメンタリー」の運営者が、自分のチャンネルの運営だけに使う制作ツールです。本ツールは YouTube API Services を使用しています。本ツールを使用することにより、YouTube 利用規約に同意したものとみなされます。Google によるデータの取り扱いについては Google プライバシーポリシー（http://www.google.com/policies/privacy）をご覧ください。

1. アクセスする情報

  • 運営者本人の YouTube チャンネルの基本情報（チャンネル ID・名前）
  • 運営者本人がアップロードした動画の情報（タイトル・公開状態・公開日時）
  • 運営者本人のチャンネルの統計（再生回数・視聴維持率・高評価数などの集計値）

本ツールは運営者以外のユーザーのアカウントにはアクセスせず、視聴者個人を特定できる情報（名前・メールアドレス・コメント本文など）は取得しません。

2. 利用目的

動画のアップロードと公開予約、および次の企画・投稿時刻の改善のための集計にのみ使用します。広告・販売・第三者への提供には使用しません。

3. 保存と共有

  • 取得した統計の集計値は、運営者の非公開の GitHub リポジトリに保存します。第三者には共有・販売しません。
  • 本ツールは Cookie や類似の技術を使用せず、ユーザーの端末に情報を保存しません。
  • 処理は GitHub Actions（GitHub, Inc.）上で行います。Google アカウントの認証情報（OAuth トークン）は暗号化されたシークレットとして保存されます。

4. 保存期間と削除

  • 再生回数などの統計の集計値は最長36か月保存し、その後削除します。
  • 統計以外の API データ（動画タイトルなど）は30日ごとに更新し、不要になったものは削除します。
  • 本ツールの Google アカウントへのアクセス権は、Google セキュリティ設定のアクセス権ページからいつでも取り消せます。取り消し後、本ツールは新たなデータを取得できず、保存済みのデータは削除のご依頼から7日以内に削除します。

5. お問い合わせ

本ポリシーに関するお問い合わせ・データ削除のご依頼は zundamon.commentary@gmail.com までご連絡ください。

English

"ずんだもん解説ショート投稿" (Zundamon Shorts Publisher) (the "Tool") is an internal production tool used solely by the owner of the YouTube channel "Zundamon Commentary" to manage the owner's own channel. The Tool uses YouTube API Services. By using the Tool, you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy.

Information accessed: the owner's own channel ID and name; metadata of videos uploaded by the owner (title, privacy status, publish time); aggregated statistics of the owner's own channel (views, average view duration, likes). The Tool never accesses other users' accounts and does not collect personal information of viewers.

Use: uploading and scheduling the owner's videos, and analyzing aggregate performance to improve future content and posting times. Data is never sold, used for advertising, or shared with third parties.

Storage and sharing: aggregated statistics are stored in the owner's private GitHub repository and processed on GitHub Actions. OAuth tokens are stored as encrypted secrets. The Tool does not use cookies or store information on users' devices.

Retention and deletion: aggregated statistics are kept for at most 36 months; other API data is refreshed or deleted within 30 days. Access can be revoked at any time via the Google security settings page. Stored data will be deleted within 7 days of a deletion request.

Contact: zundamon.commentary@gmail.com
